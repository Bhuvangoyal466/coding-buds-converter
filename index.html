🧙 Web Wizard Tutorial

                    

                        Put Your Webpage on the Internet!
                    

                    

                        You've written your code and converted it above. Now
                        let's publish it so anyone can visit it. Five small
                        steps, and you're live.
                    


                    

                        

                            

                                
1

                                
Create Your GitHub Account

                            

                            

                                📚
                                Think of it like this: GitHub
                                is a giant online library for code. Once you
                                sign up, you get your very own shelf with your
                                name on it.
                            

                            
    
                                
  1. 
                                    Go to
                                    github.com ↗.
                                
    2. 
                                
  2. 
                                    Click
                                    Sign up —
                                    it's free.
                                
    3. 
                                
  3. 
                                    Enter your email, pick a username and create
                                    a strong password.
                                
    4. 
                                
  4. 
                                    Finish the sign-up steps and verify your
                                    email.
                                
    5. 
                            

                            
                            

                                🪄
                                

                                    Wizard Tip: Your username
                                    becomes part of your webpage address, so
                                    keep it short, with no spaces. Use dashes
                                    instead (like cool-coder).
                                

                            

                        


                        
· · ·


                        

                            

                                
2

                                
Turn Your Code Into a Webpage

                            

                            

                                ✨ Think of it like this: The
                                converter at the top of this page is a magic
                                translator. It turns your code into HTML — the
                                language every web browser understands.
                            

                            
    
                                
  1. 
                                    Scroll up to
                                    the converter ↑.
                                
    2. 
                                
  2. Paste your code into the big box.
    3. 
                                
  3. 
                                    Click
                                    Convert to HTML →.
                                
    4. 
                                
  4. 
                                    Click
                                    Copy HTML (or
                                    download index.html).
                                
    5. 
                            

                            
                            

                                🪄
                                

                                    Wizard Tip: You don't need
                                    to understand the HTML! Just make sure you
                                    copy all of it.
                                

                            

                        


                        
· · ·


                        

                            

                                
3

                                
Create Your Repository

                            

                            

                                🎒 Think of it like this: A
                                repository (or "repo") is a magic backpack that
                                keeps all the files for one project together.
                            

                            
    
                                
  1. 
                                    Go back to GitHub and click
                                    New to start
                                    a repository.
                                
    2. 
                                
  2. 
                                    Give it a name with no spaces (for example
                                    my-first-webpage).
                                
    3. 
                                
  3. Choose Public.
    4. 
                                
  4. 
                                    Click
                                    Create repository.
                                
    5. 
                            

                            
                            

                                🪄
                                

                                    Wizard Tip: On the next
                                    page, look for the
                                    "creating a new file" link. That's
                                    where we're heading next!
                                

                            

                        


                        
· · ·


                        

                            

                                
4

                                
Add Your HTML Code

                            

                            

                                🚪 Think of it like this:
                                index.html is the front door of
                                your website. It's the first file a browser
                                opens when someone visits.
                            

                            
    
                                
  1. 
                                    Click creating a new file.
                                
    2. 
                                
  2. 
                                    Name the file exactly
                                    index.html (all lowercase).
                                
    3. 
                                
  3. 
                                    Paste the HTML you copied into the big
                                    editor.
                                
    4. 
                                
  4. 
                                    Click
                                    Commit changes, then click
                                    Commit changes
                                    again in the pop-up to save.
                                
    5. 
                            

                            
                            

                                🪄
                                

                                    Wizard Tip: Spelling
                                    matters! If it isn't
                                    index.html, your site won't
                                    show up. Next stop: the
                                    Settings tab.
                                

                            

                        


                        
· · ·


                        

                            

                                
5

                                
Go Live on the Internet!

                            

                            

                                🪟
                                Think of it like this: GitHub
                                Pages opens the curtains so the whole
                                neighborhood can see your drawing in the window.
                            

                            
    
                                
  1. 
                                    Open the Settings tab of
                                    your repository.
                                
    2. 
                                
  2. 
                                    Click Pages in the left
                                    menu.
                                
    3. 
                                
  3. 
                                    Under "Branch", change
                                    None to
                                    main.
                                
    4. 
                                
  4. 
                                    Click Save.
                                
    5. 
                                
  5. 
                                    Wait 1–2 minutes, refresh the page, then
                                    click
                                    Visit site.
                                
    6. 
                            

                            
                            

                                🪄
                                

                                    Wizard Tip: Your site lives
                                    at
                                    your-username.github.io/your-repo-name. Share that link with anyone, anywhere in
                                    the world!
